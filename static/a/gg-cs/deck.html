03 · The decision

Not another KRAFT.

Working title KRAFT Garten, 2021

→

A name that says where you are

Vienna’s first food hall should not look like the next branch of an international group. So we came up with a new name: Gleis = Tracks // Garten because we planted trees in the old work trenches.
